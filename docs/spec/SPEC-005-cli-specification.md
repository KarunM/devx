# SPEC-005: CLI Specification

- Status: Draft
- Version: 1.0

# Purpose

Defines the public command-line interface for ECP.

# Commands

ecp index
ecp ask
ecp search
ecp snapshot
ecp expand
ecp patch
ecp build
ecp test
ecp diagnostics

# Principles

- Human friendly
- Scriptable
- Deterministic
- Provider agnostic

# Output

Commands should support human-readable and JSON output modes.
