# PLAN-001: Indexing MVP

## Goal

Build the first structural repository index.

## Scope

- Discover projects
- Discover files
- Parse C#
- Extract namespaces
- Extract types
- Extract methods
- Store in SQLite

## Acceptance Criteria

- Repository indexed successfully
- Search by symbol
- File snapshots available

## Out of Scope

- Embeddings
- Git history
- Incremental indexing
