# Glossary

## Repository
A source code repository managed by ECP.

## Project
A buildable unit within a repository.

## Symbol
A named program element (type, method, property, field, etc.).

## Snapshot
A metadata-only view of an artifact.

## Expansion
Retrieval of additional detail, including source when requested.

## Working Set
The current collection of context owned by the Session Manager.

## Session
A persisted engineering interaction managed by the CLI.

## Patch
A structured representation of a code change.

## Diagnostic
A compiler, analyzer, or test message.

## Context Level
The amount of information exposed by the protocol, from search results to implementation.
