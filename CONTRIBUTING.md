# Contributing to DevX

Build with `dotnet build DevX.sln`; test with `dotnet test tests/DevX.Tests/DevX.Tests.csproj`. Open a focused PR describing impact and validation, and respond to review feedback. A signed [CLA](CLA.md) is required before merge.

New source files may carry `// SPDX-License-Identifier: Apache-2.0`; no mass header edit is needed. Follow the [Code of Conduct](CODE_OF_CONDUCT.md) and see [Security](SECURITY.md).
